# Tugas Web Pertemuan 6 - Interactive Quiz App

Repository ini berisi Tugas Rutin Pertemuan 6 mata kuliah Pemrograman Web.

## Deskripsi

Interactive Quiz App dibuat menggunakan HTML, CSS, dan JavaScript dengan penerapan DOM Manipulation, Event Handling, Event Delegation, dan LocalStorage.

## Fitur Utama

- 10 soal pilihan ganda setiap permainan
- Soal diacak secara otomatis
- Pilihan kategori soal
- Skor otomatis
- High score tersimpan di LocalStorage
- Navigasi tanpa reload halaman
- Feedback jawaban benar dan salah
- Tombol restart quiz
- Jumlah jawaban benar dan salah
- Informasi kategori pada hasil quiz
- Tombol kembali ke menu

## Fitur Bonus

- Timer setiap soal
- Progress bar visual
- Kategori soal dan random question
- Animasi transisi antar soal
- Dark mode toggle

## Teknologi

- HTML5
- CSS3
- JavaScript ES6+
- DOM Manipulation
- Event Delegation
- LocalStorage

## Mata Kuliah

Pemrograman Web
